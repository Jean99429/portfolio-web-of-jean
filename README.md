# Web of Jean

Jean's personal portfolio website, featuring selected AI product and experience design work.

## Live site

<https://jean99429.github.io/portfolio-web-of-jean/>

## Local preview

This is a static website with no build step.

```bash
python3 -m http.server 8000
```

Then open <http://127.0.0.1:8000/>.

## Structure

- `index.html`, `styles.css`, and root JavaScript files power the homepage.
- `assets/` contains homepage media and fonts.
- `content/` contains the four published case-study pages and their runtime assets.
